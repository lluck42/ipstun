相关软件推荐

下面列出的软件都可以在拿到公网 IP 后，直接输入 IP 地址进行连接。

远程桌面

在软件地址栏里填入 IP，即可远程控制另一台电脑的桌面。

Windows 远程桌面（RDP）

Windows 专业版/企业版自带。在「远程设置」里开启后，用「远程桌面连接」输入 IP 或 [IPv6]:3389 即可连入。

命令行与服务器管理

管理 Linux、NAS、路由器或树莓派时，SSH 是最轻量的方式。

Windows Terminal + OpenSSH

Windows 10/11 已内置 OpenSSH 客户端，直接在终端执行 ssh user@IP 或 ssh user@[IPv6] 即可登录。

PuTTY / Tabby

经典的 SSH 客户端。在 Host Name 里填入 IP 即可连接；Tabby 界面更现代，支持多标签和 SFTP。

WinSCP / FileZilla

通过 SFTP/FTP 在本地与远程设备之间传输文件，主机地址栏填入 IP 和端口，输入账号密码即可连接。

文件同步与 P2P 传输

两台设备之间直接传文件或保持文件夹同步，无需经过网盘中转。

Syncthing

开源 P2P 文件同步工具。默认通过发现服务器寻址，也可在设备地址里手动填入 tcp://IP:22000 实现直连。

LocalSend

局域网或公网间互传文件，无需注册，在发送界面输入对方设备的 IP 地址即可发送。

远程唤醒与网络工具

如果目标设备关机了，可以先唤醒它，再用远程桌面或 SSH 连接。

WakeMeOnLan

在主板和网卡开启 WOL 后，向目标 IP 或局域网广播地址发送魔术包，即可唤醒关机设备。

Advanced IP Scanner

扫描指定 IP 段内的在线设备，查看 IP、MAC 地址和开放端口，方便确认目标是否可达。

虚拟组网

如果你不想直接暴露 IPv6，也可以把多台设备组成一个虚拟局域网。

WireGuard

轻量高效的 VPN 协议。服务端配置里需要填写对端公网 IP 或域名，客户端再连入这个端点，把外出设备安全接回家中网络。

游戏与媒体串流

利用 IPv6 的大带宽和低延迟，把家里电脑的画面串到手机或另一台电脑上。

Moonlight + Sunshine

开源游戏串流方案。Sunshine 作为服务端运行在 Windows，Moonlight 客户端里输入服务端的 IP 地址，即可开始串流。

Jellyfin / Plex

自建家庭影音服务器，通过浏览器或客户端访问 http://[IPv6]:8096 之类的地址，就能在外网播放家里的影片。

提示：使用这些软件前，请确保目标设备已开启对应服务（如 RDP、SSH、WOL），并且防火墙放行相应端口。IPv6 地址输入时建议用方括号包裹，例如 [2001:db8::1]:3389。
