IPv6 动态同步助手

实时监测本机 IPv6 地址变化，自动更新到 DNS 或共享接口，防止运营商前缀变动导致失联。

工具介绍

这是一款为 Windows 设计的轻量级小工具，专门解决“家宽 IPv6 前缀会变”的问题。它会在后台监测你选中的网卡，一旦发现全球单播 IPv6 地址发生变化，就自动把它更新到域名解析（DDNS）或你指定的 HTTP 接口，让外网设备始终能通过同一个域名或链接找到你。

计划功能

  • 自动识别并选择本机网卡，过滤出真正的公网 IPv6 地址
  • 定时检测 IPv6 变化，变化后立即触发更新
  • 支持常见 DNS 服务商 API（Cloudflare、阿里云、腾讯云、DNSPod 等）
  • 支持自定义 Webhook / HTTP 接口，把最新地址推送到自己的服务器
  • 可选最小化到系统托盘，开机自启
  • 本地日志记录，方便排查同步失败问题

适用场景

  • 远程访问家里的 NAS、树莓派、Windows 远程桌面
  • 两台设备之间直接建立 P2P 连接，无需中转服务器
  • 把动态 IPv6 绑定到固定域名，分享给朋友或自用

系统要求

  • 操作系统：Windows 10 / Windows 11
  • 网络：已开启并分配公网 IPv6 的家宽网络
  • 需要一个已配置好的域名或自建接收接口
  • 体积：预计小于 10 MB
