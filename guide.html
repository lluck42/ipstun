如何查看自己的 IP 地址

覆盖 Windows、macOS、Linux、手机、路由器与在线工具，重点讲解 IPv6 的获取方法。

一、用浏览器最快查看公网 IP

如果你只想知道自己对外访问互联网时用的 IP（公网 IP），访问下面任意一个网站即可：

  • ip.sb
  • ip138.com
  • test-ipv6.com（专门检测 IPv6）
提示：如果网站显示了 IPv6 地址，说明你的网络和运营商已经支持 IPv6；如果只显示了 IPv4，可能是路由器或光猫没有开启 IPv6。

二、Windows 系统查看 IP 与 IPv6

方法 1：命令提示符（CMD）

  1. 按 Win + R，输入 cmd，回车。
  2. 输入下面命令并回车：
ipconfig /all

在输出中找到你正在使用的网卡（例如“以太网适配器”或“无线局域网适配器”），你会看到：

  • IPv4 地址：通常是 192.168.x.x 或 10.x.x.x，这是内网地址。
  • IPv6 地址：通常以 240e、2408、2409（国内运营商）或 2xxx: 开头，这是公网 IPv6。
  • 临时 IPv6 地址：Windows 会同时显示“IPv6 地址”和“临时 IPv6 地址”，前者更稳定，后者用于对外发起连接时保护隐私。

方法 2：PowerShell（更简洁）

Get-NetIPAddress -AddressFamily IPv6 | Select-Object IPAddress, PrefixLength

如果想只看 IPv4，把 IPv6 改成 IPv4 即可。

三、macOS 查看 IP 与 IPv6

方法 1：终端命令

打开“终端”，输入：

ifconfig

找到你当前连接的网络接口（Wi-Fi 通常是 en0，有线通常是 en1 或类似名称），查看 inet（IPv4）和 inet6（IPv6）后面的值。

方法 2：图形界面

  1. 点击屏幕左上角苹果菜单 → 系统设置 → 网络。
  2. 选择当前连接的网络，点击“详细信息”。
  3. 在 TCP/IP 标签页中即可看到 IPv4 和 IPv6 地址。

四、Linux 查看 IP 与 IPv6

大多数现代 Linux 发行版推荐使用 ip 命令：

ip addr

或者使用传统命令：

ifconfig

在输出中：

  • inet 后面是 IPv4 地址。
  • inet6 后面是 IPv6 地址。
  • 以 fe80: 开头的是“链路本地地址”，只在当前局域网有效，不是公网 IPv6。

五、手机端查看 IP

Android

  1. 设置 → WLAN → 点击当前连接的 Wi-Fi 名称。
  2. 在网络详情里可以看到 IPv4 和 IPv6 地址。

iOS / iPadOS

  1. 设置 → 无线局域网 → 点击当前 Wi-Fi 右侧的“i”图标。
  2. 向下滚动即可看到 IPv4 地址和 IPv6 地址。

六、从路由器后台查看公网 IP

  1. 在浏览器地址栏输入路由器管理地址，常见的是 192.168.1.1、192.168.31.1 或 tplogin.cn 等品牌地址。
  2. 登录管理员账号。
  3. 找到“上网设置 / WAN 口设置 / 网络状态”，即可看到路由器获取到的公网 IPv4 和 IPv6。
注意：很多家用宽带拿到的是“运营商级 NAT（大内网）IPv4”，并不是真正的公网 IPv4，但 IPv6 通常是直接分配到设备的公网地址。

七、如何判断看到的是不是真正的公网 IPv6？

  • 公网 IPv6：通常以 2xxx: 或 3xxx: 开头，可以在外网直接访问（配合防火墙设置）。
  • 链路本地 IPv6：以 fe80: 开头，只在当前网段内有效，不是公网地址。
  • 唯一本地地址：以 fd00: 开头，类似 IPv4 的内网地址，也不对外。

最简单的方法：用浏览器访问 test-ipv6.com，它会自动告诉你当前连接的公网 IPv6 是多少。

八、安全与隐私提示

  • 公网 IPv6 可能直接暴露你的设备，建议开启系统防火墙，不要随意对外暴露服务端口。
  • 在公开场合分享自己的 IP 截图时，建议打码处理。
  • Windows 默认会启用“临时 IPv6 地址”对外通信，能在一定程度上保护隐私。

十、IPv6 地址变了怎么办？动态前缀与 DDNS

很多家庭宽带的 IPv6 前缀不是永久固定的。运营商可能会定期重新分配前缀（Prefix），比如从 240e:123:456::/60 变成 240e:123:789::/60，一旦变了，你记住的 IPv6 地址就会失效。

为什么前缀会变？

  • 运营商为了地址管理、负载均衡或安全策略，会周期性刷新前缀。
  • 光猫或路由器重启后，重新拨号时也可能拿到新的前缀。
  • 国内三大运营商的家宽通常不会承诺固定 IPv6 前缀。

解决方案：DDNS（动态域名解析）

与其记一长串 IPv6 地址，不如给设备绑定一个域名。当 IPv6 变化时，自动更新这个域名对应的 DNS 记录，这样你始终可以通过同一个域名访问设备。

  1. 准备一个域名，并在 DNS 服务商（如 Cloudflare、阿里云、腾讯云、DNSPod）创建一条 AAAA 记录。
  2. 在设备上运行一个 DDNS 客户端，定期检查当前 IPv6。
  3. 发现变化后，调用 DNS 服务商的 API 更新 AAAA 记录。
  4. 外网访问时直接输入域名，无需关心底层 IPv6 是否改变。
提示：如果你不想自己写脚本，可以等本站即将发布的 IPv6 动态同步助手。它会自动监测本机 IPv6 变化并更新到 DNS，省去手动维护的麻烦。
