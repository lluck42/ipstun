关于 ipstun

一个让你随时随地找到任意设备外网 IP 的小工具。

本站是做什么的？

ipstun 是一个多设备外网 IP 实时同步小站。它解决一个常见但容易被忽略的问题：当你的设备处于不同网络（家里的 NAS、办公室的电脑、手机热点），你想要直接访问它们时，往往不知道它们当前的外网 IP 是什么，尤其是 IPv6 地址。

通过 ipstun，你可以让每台设备定时上报自己的公网 IP，然后在任何地方输入该设备的 device_key 就能查到它当前的地址。如果设备支持 IPv6，你甚至可以直接点对点访问，无需中转服务器。

技术栈

  • 前端：纯 HTML / CSS / JavaScript，无第三方框架，轻量易维护。
  • 后端：Cloudflare Pages Functions（基于 Workers 运行时）。
  • 数据存储：Cloudflare KV，用于保存每个设备最新的 IP 与更新时间。
  • 部署：Cloudflare Pages，静态页面与接口一起发布。

隐私与安全

本站不收集用户名、密码或其他身份信息。KV 中只保存以下内容：

  • 设备名（由你自定义）
  • 设备的公网 IPv6 或 IPv4 地址
  • 最近一次上报时间
注意：当前使用单个 device_key 同时作为查询和更新凭证。任何知道该密钥的人都能查看或修改对应设备的 IP，请妥善保管，不要公开分享。
