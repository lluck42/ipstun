为什么需要关注 IPv6？

IPv4 地址已经接近枯竭，而 IPv6 提供了几乎无限的地址空间，是未来互联网的主流协议。很多家庭宽带其实已经分配了 IPv6，只是你不知道怎么查看。

地址更多

IPv6 可以为地球上的每一粒沙子都分配一个独立地址，彻底解决地址不够用的问题。

直连更顺畅

在 IPv6 环境下，设备之间可以更容易地直接通信，不必经过复杂的 NAT 转换。

未来必备

越来越多的网站、云服务和物联网设备默认使用 IPv6，掌握它会让你更懂网络。

三种常用查询方式

在线网站

打开浏览器访问 ip.sb、ip138 或 test-ipv6.com，即可看到当前公网 IP 和 IPv6。

系统命令

Windows 用 ipconfig，macOS / Linux 用 ifconfig 或 ip addr，手机可在 Wi-Fi 详情里查看。

路由器后台

登录家用路由器的管理页面，通常能看到 WAN 口获得的公网 IPv4 和 IPv6 地址。
